组件文案由 `ThyI18nService` 保存为一份信号。日期格式语言是另一条路径，见[日期与时间](date-time.md)。`@ngx-translate/core` 出现在仓库的开发依赖里，组件库源码不导入它。

## 语言包

内置五种 id：`zh-hans`、`zh-hant`、`en-us`、`ja-jp`、`de-de`。每种都可以用同名令牌整包替换，例如 `THY_I18N_ZH_HANS`。服务构造时可选注入这些令牌，没有提供者就用内置包。测试通过替换简体中文的 `calendar.today` 来确认覆盖生效。

`THY_I18N_LOCALE_ID` 设置初始语言。没有这个令牌时，`getDefaultLocaleId()` 读取 `navigator.language`。把下划线换成连字符并转小写后，只有完整命中五种 id 才采用；`zh-cn` 这种值不在列表里，回落 `zh-hans`。浏览器环境不存在时同样回落简体中文。

## 切换如何传到组件

`setLocale` 先做同样的规范化。结果里包含 `zh`、但又不是 `zh-hans` 或 `zh-hant` 时，强制改成 `zh-hans`。测试用 `zh-ch` 覆盖了这条规则。找不到对应语言包时，用默认语言包；默认也没有则设成空对象。

`getLocale()` 返回那份 `Signal`。`injectLocale()` 用 `computed` 读它：传入 `datePicker`、`form`、`dialog` 这类模块名时返回该段；该段缺失时退回整包。组件在字段初始化时调用 `injectLocale`，语言信号一变，计算信号就会变。表单校验、日期快捷项、时间面板和日历头部都是这样取文案的。

这不会自动调用 `TinyDate.setDefaultLocale`。星期和月份的 date-fns 格式仍要应用自己同步。

## ThyTranslate 与 ngx-translate

`ThyTranslate` 是 `providedIn: 'root'` 的空实现：`instant` 直接返回传入的 key，`get` 把同一个 key 交给观察者。对话框标题、表单分组标签和勾选控件的 `thyLabelTextTranslateKey` 会调用它。测试里用 `useClass` 换成会查表的假实现。库自己没有把这个类接到 `TranslateService`。

Angular 的 `registerLocaleData` 也不在库内调用。应用如果要让日期管道和货币管道跟着语言走，需要自己注册。
